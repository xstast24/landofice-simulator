# Land of Ice - simulátor

## Jak spustit / instalovat 
Makefile `make info` popisuje:
- Nahrávání na public server
- Pouštění lokálního serveru (s Dockerem i bez něj)

### Dulezite info (read before release)
- Pri zmenach javascriptu JE NUTNE zvednout verzi v config.ini,
aby se aktualizovaly cachovane soubory v prohlizecich uzivatelu.
- Podporovana PHP verze je v config.ini, aktualne PHP 7.4 (4/2023)
- Pridani/zmena souboru je nutno reflektovat v release skriptu
(release script bere pouze urcene soubory, aby nenahraval nechtene veci)
